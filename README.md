## 프로젝트 개요

본 프로젝트는 C++98 표준을 준수하여 IRC (Internet Relay Chat) 서버를 구현하는 과제입니다.  
실제 IRC 클라이언트를 통해 서버에 접속하여 테스트할 수 있으며, 인터넷의 기본적인 통신 프로토콜에 대한 이해를 높이는 것을 목표로 합니다.

## 구현 내용

### 필수 요구사항

* 서버는 동시에 여러 클라이언트를 처리할 수 있어야 하며, 멈추지 않아야 합니다.
* Forking을 사용하지 않고, 모든 I/O 작업은 비동기적으로 처리되어야 합니다.
* poll() (또는 이와 동등한 함수)를 사용하여 모든 I/O 작업을 처리해야 합니다.
* 클라이언트는 서버에 접속하여 인증, 닉네임 및 사용자 이름 설정, 채널 참여, 개인 메시지 송수신이 가능해야 합니다.
* 채널 운영자와 일반 사용자를 구분하여 관리해야 합니다.
* 채널 운영자를 위한 명령어 (KICK, INVITE, TOPIC, MODE)를 구현해야 합니다.
* MODE 명령어는 채널의 모드를 변경하는 기능을 제공해야 합니다 (i, t, k, o, l).
* 코드의 가독성과 유지보수성을 위해 클린 코드(Clean Code) 원칙을 준수하여 작성해야 합니다.
* Makefile을 통해 컴파일을 관리하며, 필요한 규칙 (NAME, all, clean, fclean, re)을 포함해야 합니다.
* 프로그램은 예기치 않은 상황에서도 종료되지 않고 안정적으로 동작해야 합니다.

### 보너스 요구사항

* 파일 전송 기능 구현
* 봇 (Bot) 구현

## 사용 방법

1.  **컴파일:**
    ```bash
    make
    ```
2.  **실행:**
    ```bash
    ./ircserv <포트 번호> <비밀번호>
    ```
    * `<포트 번호>`: 서버가 수신 대기할 포트 번호
    * `<비밀번호>`: 서버 접속 시 필요한 비밀번호
3.  **클라이언트 접속:**
    * 원하는 IRC 클라이언트를 실행하고, 위에서 지정한 포트 번호와 비밀번호를 사용하여 서버에 접속합니다.

## 테스트 방법

* nc 명령어를 사용하여 서버의 동작을 간단하게 테스트할 수 있습니다.
    ```bash
    nc -C 127.0.0.1 6667
    ```
* Ctrl+D를 사용하여 명령어를 여러 부분으로 나누어 보내고, 서버가 이를 제대로 처리하는지 확인할 수 있습니다.
* 다양한 IRC 클라이언트를 사용하여 서버의 기능을 테스트하고, 예외 상황에 대한 처리도 꼼꼼하게 검증합니다.
